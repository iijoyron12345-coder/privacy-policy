## 個人情報の収集について

本アプリは、ユーザーの個人情報（氏名、メールアドレス、電話番号等）を収集しません。

## データの保存について

お気に入り、マイプラン、実施済みの記録はすべてお使いの端末内にのみ保存されます。外部サーバーへの送信は行いません。

## 広告について

本アプリはGoogle AdMobによる広告を表示しています。AdMobは広告配信のために匿名の識別情報を使用する場合があります。詳細はGoogleのプライバシーポリシーをご確認ください。
https://policies.google.com/privacy

## 第三者へのデータ提供

本アプリは収集した個人情報を第三者に提供することはありません。
